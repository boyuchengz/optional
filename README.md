## Hold. Tap. Let go.

| Hold | Tap | Let go |
| :--- | :--- | :--- |
| <kbd>⌥</kbd>, or any key you choose. | A letter opens a wheel. Tap again to move. | It runs. <kbd>Esc</kbd> backs out. |

## Thirteen wheels. Already full.

Nothing to set up. Each one fills with what you’re doing right now. Hold <kbd>⌥</kbd> and tap:

| Key | Wheel | What’s in it |
| :---: | :--- | :--- |
| <kbd>L</kbd> | **Latest** | The screenshot you just took, the file you just downloaded, what you just copied. |
| <kbd>V</kbd> | **Clipboard** | Text, images, files, links and colors. Let go to paste, hold Shift for plain text. |
| <kbd>Tab</kbd> | **Windows** | Every window, including minimized ones and those on other desktops. |
| <kbd>F</kbd> | **Recent&nbsp;Files** | Screenshots, downloads and files you just saved, ready to paste into a chat. |
| <kbd>A</kbd> | **Audio** | Speakers, headphones and microphones. |
| <kbd>B</kbd> | **Bluetooth** | Connect or disconnect paired devices. |
| <kbd>T</kbd> | **Browser&nbsp;Tabs** | Every tab in Safari, Chrome, Arc, Edge and Brave. |
| <kbd>I</kbd> | **Input&nbsp;Sources** | English, Pinyin, 日本語 and the rest. |
| <kbd>C</kbd> | **Meetings** | Your next meetings. Let go to join the call. |
| <kbd>S</kbd> | **System&nbsp;Toggles** | Dark Mode, Wi-Fi, Night Shift, Keep Awake and more, plus any Shortcut. |
| <kbd>O</kbd> | **Favorite&nbsp;Apps** | Eight apps in spots that never move, so your hand learns where they are. |
| <kbd>M</kbd> | **App&nbsp;Commands** | The front app’s commands in fixed spots. Type to find any menu item. |
| <kbd>Space</kbd> | **Context** | The right actions for what you’ve selected. |

Each wheel can be a Command-Tab-style row, a round wheel or a list. Keys, size and color are yours to change.

## A clipboard that reads the room.

The same copies, in the order the place you paste into wants.

| Pasting into | Comes first |
| :--- | :--- |
| A browser’s address bar | Links |
| WeChat, Slack, Messages | Images and files |
| Terminal | Commands and paths |
| Code editors | Code |
| Figma and other design apps | Colors and images |

Tap <kbd>Space</kbd> to stack several items: the first pastes when you let go, and each <kbd>⌘</kbd><kbd>V</kbd> after that pastes the next. Passwords, and anything an app marks as concealed, are never recorded.

## Select. ⌥ Space. Done.

The right actions for what you’ve selected, and the result lands right where it was.

| You select | You choose | It becomes |
| :--- | :--- | :--- |
| `128 × 3` | = 384 | `384` |
| `weekend in kyoto` | Change Case | `WEEKEND IN KYOTO` |
| `ryokan.example/?utm_source=ad` | Remove Tracking | `ryokan.example/` |

Also Copy as Markdown Link, Open in another browser, Space Between 中文 and English, Search the Web, Send… to AirDrop, Messages or Mail, and actions for files, images and PDFs in Finder.

## ⌥Z takes it back.

The window you switched to, the paste, the headphones. Undone.

## On your Mac.

Everything you copy stays on your Mac. There’s no account, no analytics and no ads. Optional goes online only to check for updates and, when you copy a Markdown link, to read that page’s title. [Privacy policy](https://optional.pro/privacy)

## Install

1. [Download Optional](https://optional.pro/download), open the .dmg and drag Optional to Applications.
2. Open Optional. It lives in the menu bar.
3. Allow Accessibility when it asks, then hold Left Option.

Optional updates itself. Official builds come only from [optional.pro](https://optional.pro), signed with Developer ID and notarized by Apple. [Release notes](https://optional.pro/changelog)

## Questions

<details>
<summary><b>Which Macs does it run on?</b></summary>
<br>
Macs with Apple silicon on macOS 14 Sonoma or later. That’s every Apple silicon Mac, from the 2020 M1 models on.
<br><br>
</details>

<details>
<summary><b>Why does it need Accessibility permission?</b></summary>
<br>
macOS requires it for any app that reacts to a held key, pastes for you or switches windows. Optional never records what you type. Screen Recording, Calendar and Automation are optional and only asked for when a wheel needs them.
<br><br>
</details>

<details>
<summary><b>How is this different from Raycast or Spotlight?</b></summary>
<br>
Those start with a search box: you open them, type a name, pick. Optional starts with your hand already on the key and never takes focus from your app, so it can paste where you are, act on what you’ve selected, keep every app’s commands in fixed spots and undo what it just did. Use both; they don’t overlap much in practice.
<br><br>
</details>

<details>
<summary><b>What if I already use Left Option?</b></summary>
<br>
Pick another trigger in Settings: Right Option, Right Command, Right Control, Left Control or Fn. Letters that aren’t assigned to a wheel still reach your app, and Option with another modifier (⌥⌘…) is left to the app too.
<br><br>
</details>

<details>
<summary><b>Is there a Mac App Store version?</b></summary>
<br>
No. Optional is downloaded from optional.pro, signed with Developer ID and notarized by Apple, and it updates itself.
<br><br>
</details>
